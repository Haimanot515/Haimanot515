# SafeGuard: Digital PPE Compliance & Tracking System

### Project Overview
SafeGuard replaces unreliable paper-based tracking with a digital audit trail to prevent workers from using damaged or expired safety gear. This ensures high-risk worksites remain compliant with safety regulations and reduces the risk of workplace accidents.

### Core Feature List
* **Digital PPE Inventory:** Real-time tracking of all Personal Protective Equipment (PPE) in stock.
* **Automated Expiry Alerts:** System notifications when safety gear is nearing its expiration date.
* **QR Code Equipment Check-in:** Workers scan gear via mobile app to verify safety status before use.
* **Compliance Audit Trail:** Generates digital reports for safety inspectors, replacing paper logs.
* **Incident Reporting:** Quick-access portal for workers to report damaged gear instantly.
* **Manager Dashboard:** A web-based overview for supervisors to monitor site-wide compliance.
